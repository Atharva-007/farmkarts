# 🎯 FARMKARTS - QUICK START GUIDE

## 🌍 How to Change Language

### Method 1: From Login Page
1. Look for the **globe icon (🌐)** in the top-right corner
2. Click it
3. Select your preferred language:
   - **English**
   - **हिंदी** (Hindi)
   - **मराठी** (Marathi)
4. The page updates immediately!

### Method 2: From Settings (After Login)
1. Open the **side menu** (hamburger icon ☰)
2. Click **"Settings"** (या "सेटिंग्स")
3. Under **"Appearance"**, click **"Language"**
4. Select your language
5. Click **"Cancel"** to close
6. Entire app switches to new language!

---

## 🎨 How to Change Theme

### From Settings Page
1. Open the **side menu** (hamburger icon ☰)
2. Click **"Settings"**
3. Under **"Appearance"**, click **"Theme"**
4. Choose:
   - **Light Mode** 🌞 (Bright)
   - **Dark Mode** 🌙 (Dark)
   - **System Default** 📱 (Follows phone)
5. Theme changes instantly!

---

## 🛍️ How to Shop

### Add to Cart
1. Go to **"Marketplace"** from bottom navigation
2. Click on any product
3. Adjust quantity with **+/-** buttons
4. Click **"Add to Cart"** button
5. See confirmation message ✅

### Add to Wishlist
1. Go to **"Marketplace"**
2. Click on any product
3. Click the **heart icon ❤️** in top-right
4. Product saved to wishlist!

### View Cart
1. Open **side menu** (☰)
2. Click **"Shopping Cart"**
3. See all items
4. Adjust quantities or remove items
5. Click **"Checkout"** to proceed

### View Wishlist
1. Open **side menu** (☰)
2. Click **"Wishlist"**
3. See all saved products
4. Click **"Move to Cart"** to add items

## 📞 Need Help?

**Common Issues:**

**Q: Language not changing?**
- Go to Settings → Language → Select again
- If still not working, restart app

**Q: Can't see dark mode properly?**
- Make sure "Dark Mode" is selected (not "System Default")
- Check your phone's dark mode is ON if using "System Default"

**Q: Lost items in cart?**
- Cart syncs with account - logout and login again
- Check internet connection

**Q: App in wrong language?**
- Change from Settings or Login page
- Default is English
