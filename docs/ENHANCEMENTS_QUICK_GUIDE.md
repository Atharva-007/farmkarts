## How to Use

### View Price History
```
1. Go to APMC Market page
2. Click any commodity (e.g., "Wheat")
3. Scroll to see:
   - Price History Chart (30 days)
   - Trend: +8.7% ↑ or -5.2% ↓
```

### Check Market Insights
```
1. On commodity detail page
2. Scroll to "Market Insights" section
3. See:
   - Total Markets: 45
   - States: 12
   - Total Arrivals: 2,340 Q
   - Avg/Market: 52 Q
```

### Filter by Location
```
1. On commodity detail page
2. Select State from dropdown
3. Select City from dropdown (enables after state)
4. Chart & insights update automatically
5. Price list shows filtered markets
```

### Access Settings
```
1. Open side menu (hamburger icon)
2. Scroll down
3. Tap "Settings"
4. Configure:
   - Notifications (ON/OFF)
   - Language (English, Hindi, etc.)
   - Theme (Light, Dark, Auto)
   - Location Services (ON/OFF)
```

### Change Language
```
1. Side Menu → Settings
2. Scroll to "Preferences"
3. Tap "Language" dropdown
4. Select: English, Hindi, Marathi, Tamil, or Telugu
5. Settings save automatically
```

### Enable Price Alerts
```
1. Side Menu → Settings
2. Go to "Notifications" section
3. Toggle "Price Alerts" to ON
4. Get notifications for price changes
```

### Clear Cache
```
1. Side Menu → Settings
2. Go to "Data & Privacy"
3. Tap "Clear Cache"
4. Confirm in dialog
5. Cache cleared!
```

### Logout
```
1. Side Menu → Settings
2. Scroll to bottom
3. Tap red "Logout" button
4. Confirm in dialog
5. Logged out successfully
```

## Chart Details

### Price History Chart
- **Type:** Line chart with gradient
- **Duration:** Last 30 days
- **Data:** Daily average prices
- **Colors:**
  - Green gradient = positive trend
  - Red gradient = negative trend
- **Interaction:** Tap to see exact values

### Trend Analysis
- **Formula:** ((Current - 30DaysAgo) / 30DaysAgo) × 100
- **Display:** +8.7% or -5.2%
- **Color:**
  - Green = Price increased
  - Red = Price decreased
