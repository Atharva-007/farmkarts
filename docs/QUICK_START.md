# 🚀 FarmKarts - Quick Start Guide

## For Developers

### Setup (5 minutes)
```bash
# 1. Install dependencies
flutter pub get

# 2. Run the app
flutter run

# 3. Build for production
flutter build apk --release  # Android
flutter build ios --release  # iOS
flutter build web --release  # Web
```

### Key Commands
```bash
# Hot reload
r

# Hot restart
R

# Clean build
flutter clean && flutter pub get && flutter run

# Deploy Firestore rules
firebase deploy --only firestore

# View logs
flutter logs
```

## For Users

### Login
1. Open app
2. Select language (top-right)
3. Enter email/phone
4. Enter password
5. Tap "Login"

### Change Theme
1. Tap hamburger menu (☰)
2. Scroll to "Settings"
3. Select "Theme"
4. Choose: Light, Dark, or System

### Change Language
1. Tap hamburger menu (☰)
2. Scroll to "Settings"
3. Select "Language"
4. Choose: English, Hindi, or Marathi

### Shop Products
1. Go to "Marketplace" (bottom nav)
2. Browse or search products
3. Tap product for details
4. Tap "Add to Cart" or "Buy Now"

### Wishlist
1. Tap heart icon on product
2. View wishlist from drawer menu
3. Create folders to organize

### Cart & Checkout
1. Tap cart icon (top-right)
2. Review items
3. Adjust quantities
4. Tap "Checkout"
5. Confirm order

## Troubleshooting

### App Not Loading?
- Check internet connection
- Force close and reopen
- Clear app cache
- Reinstall if needed

### Theme Not Changing?
- Restart app after changing
- Check Settings > Theme

### Language Not Changing?
- Restart app after changing
- Check Settings > Language

### Cart Empty After Login?
- Cart syncs with your account
- Make sure you're logged in
- Items persist across devices
