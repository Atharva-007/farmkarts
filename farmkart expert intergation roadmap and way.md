🧱 STEP 4 — Build the Embedding Index

Create build_index.py:

from sentence_transformers import SentenceTransformer
import faiss, os, numpy as np, json

model = SentenceTransformer('all-MiniLM-L6-v2')
DATA_DIR = "data/"

def build_index():
    docs, ids = [], []
    for fname in os.listdir(DATA_DIR):
        path = os.path.join(DATA_DIR, fname)
        if not fname.endswith(".txt"): continue
        with open(path, encoding='utf-8') as f:
            text = f.read()
            docs.append(text)
            ids.append(fname)
    embeddings = model.encode(docs)
    index = faiss.IndexFlatL2(embeddings.shape[1])
    index.add(np.array(embeddings))
    faiss.write_index(index, "embeddings.index")
    json.dump(ids, open("doc_ids.json", "w"))
    print(f"✅ Indexed {len(docs)} documents")

if __name__ == "__main__":
    build_index()


Then run:

python build_index.py


You’ll see:

⚙️ STEP 5 — Create RAG pipeline

Create rag_pipeline.py:

import faiss, json, numpy as np, subprocess
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('all-MiniLM-L6-v2')

def retrieve(query, k=3):
    index = faiss.read_index("embeddings.index")
    ids = json.load(open("doc_ids.json"))
    q_emb = model.encode([query])
    D, I = index.search(np.array(q_emb), k)
    results = []
    for i in I[0]:
        fname = ids[i]
        with open(f"data/{fname}", encoding='utf-8') as f:
            results.append(f.read())
    return results

def query_ollama(prompt):
    """Runs a prompt through Ollama locally."""
    cmd = ["ollama", "run", "phi3"]
    process = subprocess.Popen(cmd, stdin=subprocess.PIPE, stdout=subprocess.PIPE, text=True)
    output, _ = process.communicate(input=prompt)
    return output.strip()

def generate_answer(query):
    context_docs = retrieve(query)
    context = "\n\n".join(context_docs)
    prompt = f"""
You are FarmKart's agricultural expert AI.
Use the following context to answer farmer's query accurately and simply.

Context:
{context}

Question: {query}

Answer with actionable, region-relevant, safe advice for Indian farmers.
"""
    return query_ollama(prompt)

🚀 STEP 6 — Create FastAPI App

Create app.py:

from fastapi import FastAPI, Request
from rag_pipeline import generate_answer

app = FastAPI(title="FarmKart AI Expert (Local RAG)")

@app.post("/ask")
async def ask(request: Request):
    data = await request.json()
    query = data.get("query")
    answer = generate_answer(query)
    return {"query": query, "answer": answer}


Run it:

uvicorn app:app --reload --port 8000


Now test:

curl -X POST http://localhost:8000/ask -H "Content-Type: application/json" -d '{"query":"How to control rice blast disease?"}'


You should get a real answer generated by phi3 grounded in your local RAG context.

🔗 STEP 7 — Integrate with FarmKart backend

In your Node.js backend, make a proxy route that forwards Firebase-authenticated farmer queries to this local AI service.

aiProxy.js

const express = require('express');
const axios = require('axios');
const router = express.Router();

router.post('/ai/advice', async (req, res) => {
  try {
    const query = req.body.query;
    const resp = await axios.post('http://localhost:8000/ask', { query });
    res.json(resp.data);
  } catch (err) {
    res.status(500).json({ error: 'AI service error' });
  }
});

module.exports = router;


Then in your Flutter app, send POST to your Node.js backend:

🔒 STEP 9 — Security & Optimization

✅ Security

Don’t expose your FastAPI publicly (keep it internal only).

Verify API keys if needed (Header x-api-key).

Sanitize scraped text before saving.

Restrict large input lengths to prevent prompt injection.

✅ Optimization

Cache frequent answers (Redis/Firebase cache).

Use chunked docs (500 tokens each) for better retrieval.

Tune Ollama config (~/.ollama/models/phi3) for memory management.
